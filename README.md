# ZIP3_GeoJSON

US: The original shapefile for 3-digit ZIP code regions was sourced from [this GitHub repository](https://github.com/gweissman86/three_digit_zips).
CA: The original shapefile for cansus divisions was sourced from [this website]([https://github.com/gweissman86/three_digit_zips](https://www12.statcan.gc.ca/census-recensement/alternative_alternatif.cfm?l=eng&dispext=zip&teng=lcd_000b21a_e.zip&k=%20%20%20136594&loc=//www12.statcan.gc.ca/census-recensement/2021/geo/sip-pis/boundary-limites/files-fichiers/lcd_000b21a_e.zip)).
The shapefiles were converted into GeoJSON format using [MapShaper](https://mapshaper.org).
